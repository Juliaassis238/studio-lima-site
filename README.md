# Studio Lima — Site institucional

Página institucional estática do Studio Lima, com foco em depilação pelo método espanhol, estética e agendamento em Brasília/DF.

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador. O projeto é autocontido e utiliza imagens embutidas no próprio HTML, portanto não requer instalação de dependências ou servidor de aplicação.

## Publicação

Este repositório contém a versão estática enviada para publicação pública no GitHub.
